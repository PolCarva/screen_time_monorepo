# Screen Time v3 — exploración y selección

Las tres direcciones parten del mismo producto y no se mezclan automáticamente. Cada una propone una lógica propia de tipografía, color, progreso, interrupción e icono.

## Dirección A — Quiet Instrument

**Concepto**
Screen Time como instrumento de calibración: una interfaz precisa, silenciosa y mate que informa sin juzgar.

- **Mood:** técnico, estable, sobrio, casi arquitectónico.
- **Tipografía:** Onest para interfaz; IBM Plex Mono para medidas y estados.
- **Color:** chalk, graphite, dusty blue y brass apagado.
- **Materialidad:** aluminio anodizado, e-ink, leyendas grabadas y líneas de calibración.
- **UI sample:** tiempo recuperado como lectura principal; apps, decisiones e impacto alineados sobre una escala compartida.
- **Progreso:** bandas de calibración discretas que se llenan por intervalos reales.
- **Intervención:** una aguja/índice se detiene durante un segundo y habilita la elección.
- **Icono:** dos brackets enfrentados que crean una abertura central.

**Riesgo:** puede sentirse frío, demasiado próximo al rigor editorial anterior y excesivamente “instrument panel”.

## Dirección B — Soft Field

**Concepto**
La atención aparece como un campo de módulos. El uso automático produce densidad y desalineación; cada decisión consciente devuelve espacio y orden.

- **Mood:** humano, contemporáneo, táctil, inequívocamente digital.
- **Tipografía:** Recursive como sistema único; Sans lineal para UI, Mono para datos y un grado Casual mínimo para momentos humanos.
- **Color:** warm chalk, graphite, mineral blue, muted peach y fog.
- **Materialidad:** polímero mate, impresión seca, difusión localizada y microtextura sólo en módulos de datos.
- **UI sample:** una métrica protagonista y un field de siete días; la selección protegida, el impacto y el siguiente paso comparten una línea de lectura.
- **Progreso:** módulos rectangulares con altura/posición vinculadas a minutos recuperados y decisiones conscientes.
- **Intervención:** módulos densos se separan durante un segundo; el espacio resultante revela la pregunta y los CTAs.
- **Icono:** un campo mínimo de cuatro módulos, con uno desplazado para crear una abertura reconocible.

**Riesgo:** si se usan demasiados módulos puede parecer dashboard; el sistema debe reservar el field para progreso e intervención.

## Dirección C — Luminous Threshold

**Concepto**
La pausa como cambio de exposición: una interfaz de planos tranquilos donde una banda de luz funcional separa el reflejo de la elección.

- **Mood:** espacial, silencioso, fotográfico, premium.
- **Tipografía:** Geologica para producto y una variante condensed para campaña; números tabulares de la misma familia.
- **Color:** warm white, charcoal, fog blue, muted peach y un amarillo pálido funcional.
- **Materialidad:** vidrio esmerilado limitado, luz natural, superficies semitranslúcidas y fotografía de espacios.
- **UI sample:** la métrica principal vive dentro de un plano de exposición; datos secundarios aparecen como captions.
- **Progreso:** tiras de exposición que registran intervalos recuperados a lo largo del día.
- **Intervención:** la escena pierde contraste y una franja vertical abre la elección.
- **Icono:** dos planos solapados que dejan una línea luminosa.

**Riesgo:** puede derivar hacia wellness, depender demasiado de fotografía y ser difícil de reproducir en Shield/Android sin degradarse.

## Selección — Soft Field

Soft Field es la dirección más fuerte porque convierte el comportamiento central del producto en lenguaje visual sin recurrir a una metáfora literal. El field puede ser dato, progreso, motion, icono, campaña y una forma discreta de 3D; la tipografía variable permite expresar automático → consciente con la misma familia y sin parecer una app wellness.

### Reglas de selección

- No importar el brass o la aguja de Quiet Instrument.
- No importar la banda luminosa ni los efectos translúcidos de Luminous Threshold.
- El field sólo aparece cuando existe dato, progreso o transición; nunca como patrón decorativo.
- La dirección fotográfica pertenece a la marca y campaña, pero no se superpone a cada pantalla de producto.
- La profundidad 3D se reserva para resúmenes de progreso y piezas promocionales, nunca para la acción primaria.
