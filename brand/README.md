# Still brand assets

Editable source assets for the Still identity.

```text
brand/
  assets/
    logo/       master SVG marks, lockups and app icon
    patterns/   reusable interval/timestamp graphics
  campaign/
    source/     editable social, store, banner and mockup masters
    exports/    ready-to-use PNG exports
  product-screens/  verified web and iOS Release captures
```

The master mark is `assets/logo/interval-s-ink.svg`. Exported raster assets must be generated from the masters and never edited separately.

## Rules

- Keep the central interval open.
- Use one flat ink per mark.
- Do not place the mark inside a ring or halo.
- Keep clear space equal to the stroke width on every side.
- Use the mark alone below 96 px wide; use the horizontal lockup above it.
- The horizontal SVG keeps the wordmark editable and requires Familjen Grotesk 700.
